§1

Foundation

The name already tells the story. Everything else in this standard is built on it.

bench·mark noun, surveying

A fixed mark of known elevation, cut into stone or set as a bronze disk, that every other level on a job is measured from.

Each guide should work the same way for an engineer: a trusted reference to check their own calculation against. We don't sell shortcuts. We sell the fixed point.

Positioning statement

For engineering students and working engineers who need to get a calculation right the first time, Benchmark Guides are compact references built on worked examples. Each one shows every step, unit and code clause, so the answer can be checked, not just copied.

Who we write for

Primary audiences
The candidate
Preparing for licensure exams. Needs structured practice and fast lookups under time pressure.
The graduate
In their first three years on the job. Needs to see how design checks are actually done in practice.
The practitioner
Needs a reliable check between projects, outside their daily specialty.

Values

What every guide must prove

Traceable

Every number points to its source, whether that's an equation, a table or a code clause.

Exact

Every value carries units. Significant figures match the input data, no more.

Usable

You work from a guide at your desk. It isn't a textbook you have to study first.

Current

Every guide carries a revision letter, and owners get each new revision free.

§2

Logo

The mark is the cut benchmark, and it also reads as an instrument on its tripod. The wordmark is custom lettering drawn on a 100-unit grid, and GUIDES is set as its dimension line. The bronze bar is the datum. It's the only part of the logo that ever takes color.

Construction

Mark · S = overall size
  • One stroke weightBar, arrow and stem share a single stroke of 0.12 S, with square ends cut flat to the baseline.
  • The gap is the ideaThe arrow stops 1.2 stroke-widths below the bar. It points at the datum and never touches it.
  • Datum in bronzeThe bar is Survey Bronze on light grounds and Bronze Light on dark. For one-color use, the whole mark goes one color.
  • Lettering, not a fontThe wordmark is drawn by hand. Never retype it. Use the supplied files.

Typography

Three faces, each with one job. Saira's width axis echoes the wordmark's extended lettering. Source Serif carries the long explanations. Plex Mono handles anything you would read off an instrument: codes, units and revisions.

Display & UI

Saira

Weights 500–700, widths 100–125. Use it for headlines, navigation, buttons and prices. Headlines use mixed case, never all caps.

Inside the guide

Page convention · example content
BG-STR-101 · REV BLoad Paths & Tributary Areasp. 23

WE 3.2Simply supported floor beam

Given
Uniform live load w = 0.80 kip/ft, span L = 20 ft, floor member.
Find
Maximum moment, and the allowable live-load deflection.
Solution
Mmax = wL²/8 = (0.80)(20)²/8 = 40.0 kip·ft Δallow = L/360 = (240 in)/360 = 0.667 in
Check
✓ units kip·ft and in   ✓ source IBC Table 1604.3, floor members, live load

Every worked example follows Given → Find → Solution → Check. Results are highlighted in Bronze tint, and each check names its source.
